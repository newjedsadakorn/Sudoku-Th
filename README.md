# ซูโดกุ 1000 แบบฝึก — ทำเป็นแอปมือถือ

เกมทั้งเกมอยู่ใน `index.html` ไฟล์เดียว ไม่พึ่ง server ไม่พึ่ง API
เพราะแบบนี้เลยไม่ต้องเขียนใหม่ด้วย React Native หรือ Flutter
เอาไฟล์ชุดนี้ห่อเป็นแอปได้เลย

## ไฟล์ในชุดนี้

```
index.html                  เกมทั้งหมด (HTML + CSS + JS)
manifest.webmanifest        ชื่อแอป ไอคอน สีพื้น โหมดเต็มจอ
sw.js                       service worker ทำให้เล่นออฟไลน์ได้
icons/                      ไอคอน 180 / 192 / 512 / maskable
fonts/                      IBM Plex Sans Thai + Mono เก็บไว้ในเครื่อง ไม่พึ่ง Google Fonts
```

## ทางเลือกที่ 1 — PWA (แนะนำให้เริ่มทางนี้)

ผู้ใช้กด "เพิ่มไปยังหน้าจอโฮม" แล้วได้ไอคอนกับหน้าจอเต็มเหมือนแอปจริง
ไม่ต้องผ่านสโตร์ ไม่มีค่าใช้จ่าย ไม่ต้องลง Android Studio หรือ Xcode

### ขั้นตอน

1. อัปโหลดทุกไฟล์ในโฟลเดอร์นี้ขึ้นโฮสต์ที่เป็น **https** (จำเป็น ไม่งั้น service worker ไม่ทำงาน)
   ฟรีและง่าย: GitHub Pages, Netlify Drop (ลากโฟลเดอร์ไปวางบนเว็บได้เลย), Cloudflare Pages, Vercel
2. เปิดลิงก์บนมือถือ
3. **Android/Chrome** เบราว์เซอร์จะเด้งแถบ "ติดตั้งแอป" ขึ้นมาเอง หรือกดเมนูสามจุด → ติดตั้งแอป
   **iOS/Safari** กดปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม (iOS ไม่เด้งให้เอง ต้องบอกผู้ใช้)

### ข้อจำกัดที่ควรรู้ก่อนเลือกทางนี้

- iOS รองรับ PWA ได้ แต่ต้องผ่าน Safari เท่านั้น และผู้ใช้ต้องรู้วิธีกดเอง
- ถ้าผู้ใช้ iOS ลบแอปออก ข้อมูลความคืบหน้าจะหายไปด้วย
- ขึ้นสโตร์ไม่ได้ คนหาในสโตร์ไม่เจอ

### เวลาแก้เกมแล้วอัปเดต

**แก้ `index.html` อย่างเดียว** ไม่ต้องทำอะไรเพิ่ม push ขึ้น GitHub แล้วผู้ใช้
เปิดแอปครั้งถัดไปจะเห็นของใหม่เอง เพราะ service worker ตั้งให้ดึงไฟล์นี้สดทุกครั้งที่ออนไลน์

**แก้ไฟล์อื่น** (ไอคอน, manifest, ตัว sw.js เอง) ต้องเลื่อนเลข `VERSION` ใน `sw.js` ด้วย
เช่น `sudoku-v3` → `sudoku-v4` เพราะไฟล์กลุ่มนั้นเก็บไว้ในเครื่องแบบถาวร

### ถ้าอยากล้างสถิติในเครื่อง

ในแอปมีปุ่ม "ล้างสถิติทั้งหมด" อยู่ใต้รายการระดับบนหน้าแรก กดแล้วยืนยัน
ความคืบหน้าและการปลดล็อกจะกลับไปเริ่มใหม่ทั้งหมด

ถ้าอยากล้างจากนอกแอป: Android ไปที่ ตั้งค่า → แอป → เลือกแอป → ที่จัดเก็บ → ล้างข้อมูล
ส่วน iOS ให้ลบไอคอนออกจากหน้าจอโฮม ข้อมูลจะถูกลบไปด้วย

## ทางเลือกที่ 2 — Capacitor (ขึ้น Play Store / App Store)

ห่อไฟล์ชุดเดิมให้กลายเป็นแอปเนทีฟจริง ได้ไฟล์ `.aab` กับ `.ipa` ไปส่งสโตร์
โค้ดเกมไม่ต้องแก้อะไรเลยแม้แต่บรรทัดเดียว

### เตรียมเครื่อง

- Node.js 18 ขึ้นไป
- Android: Android Studio + JDK 17
- iOS: **ต้องใช้ Mac** เท่านั้น + Xcode (ข้อนี้เลี่ยงไม่ได้)

### คำสั่ง

```bash
mkdir sudoku-app && cd sudoku-app
npm init -y
npm i @capacitor/core @capacitor/cli
npx cap init "ซูโดกุ" com.yourname.sudoku --web-dir=www

mkdir www
# คัดลอก index.html, manifest.webmanifest, sw.js และโฟลเดอร์ icons ไปไว้ใน www/

npm i @capacitor/android
npx cap add android
npx cap sync
npx cap open android          # Android Studio จะเปิดขึ้นมา กด Build > Generate Signed Bundle

# ฝั่ง iOS (ทำบน Mac)
npm i @capacitor/ios
npx cap add ios
npx cap sync
npx cap open ios              # Xcode เปิดขึ้นมา ตั้ง Signing แล้ว Archive
```

ทุกครั้งที่แก้ `index.html` ให้คัดลอกทับใน `www/` แล้วสั่ง `npx cap sync` ใหม่

### ปลั๊กอินที่ควรใส่เพิ่ม

```bash
npm i @capacitor/haptics        # สั่นแบบเนทีฟ ดีกว่า navigator.vibrate มาก (iOS รองรับด้วย)
npm i @capacitor/preferences    # เก็บความคืบหน้าแบบเนทีฟ ไม่โดนระบบล้างเหมือน localStorage
npm i @capacitor/status-bar     # คุมสีแถบสถานะด้านบน
```

`@capacitor/preferences` สำคัญที่สุดในสามตัวนี้ เพราะ localStorage บน iOS
ถูกระบบล้างได้เองถ้าไม่ได้เปิดแอปนานๆ สถิติที่ผู้ใช้สะสมมาจะหาย

### ค่าใช้จ่ายและเวลารอ

| | Google Play | App Store |
|---|---|---|
| ค่าสมัคร | 25 USD จ่ายครั้งเดียว | 99 USD ต่อปี |
| เวลารีวิว | 1–7 วัน | 1–3 วัน |
| เครื่องที่ต้องใช้ | Windows/Mac/Linux ก็ได้ | ต้องมี Mac |

## ทางเลือกที่ 3 — เขียนใหม่ด้วย React Native หรือ Flutter

**ไม่แนะนำสำหรับเกมนี้** เกมไม่ได้ใช้ความสามารถเนทีฟอะไรเลย
(ไม่มีกล้อง ไม่มี GPS ไม่มี push notification) การเขียนใหม่คือเสียเวลาหลายสัปดาห์
เพื่อผลลัพธ์ที่ผู้ใช้แยกไม่ออกจาก Capacitor

จะคุ้มก็ต่อเมื่อคิดจะเพิ่มของพวกนี้ทีหลัง: เล่นแข่งกันแบบเรียลไทม์,
แจ้งเตือนประจำวัน, ซิงก์ข้ามเครื่อง, ซื้อภายในแอป

## สิ่งที่ปรับไว้แล้วในเวอร์ชันนี้

- กันดับเบิลแท็ปแล้วซูม และกันดึงหน้าจอลงแล้วรีเฟรชกลางเกม
- กดค้างบนกระดานไม่เด้งเมนูคัดลอกข้อความ
- กระดานย่อเองถ้าจอเตี้ย จะได้ไม่ต้องเลื่อนหน้าจอขณะเล่น
- เผื่อพื้นที่ให้แถบท่าทางด้านล่างของ iPhone
- ขอ wake lock ระหว่างเล่น จอไม่ดับตอนนั่งคิดนาน
- สลับไปแอปอื่นแล้วเกมพักให้เอง เวลาจะได้ไม่เดินทิ้ง
- สั่นสั้นๆ เมื่อลงเลขผิด และสั่นสามจังหวะเมื่อทำเสร็จ
- ที่เก็บข้อมูลไล่หาทีละชั้น: window.storage → localStorage → หน่วยความจำ

## สิ่งที่ยังไม่ได้ทำ

- ยังไม่มีระบบซิงก์ข้ามเครื่องอัตโนมัติ ใช้ปุ่มสำรอง/กู้คืนในหน้าตั้งค่าแทน
- ยังไม่รองรับโปรแกรมอ่านหน้าจอเต็มที่ (ช่องในตารางไม่มี aria-label บอกตำแหน่ง)
- สร้างโจทย์ระดับยากใช้เวลาสั้นๆ บนเธรดหลัก บนมือถือรุ่นเก่าอาจรู้สึกสะดุด

## สิ่งที่เกมทำได้ตอนนี้

**การเล่น** ซูโดกุ 1000 ข้อ แบ่ง 5 ระดับ ระดับละ 200 ข้อ หน้าละ 25 ข้อ 8 หน้า
โจทย์ไม่ได้ฝังไว้ในไฟล์แต่สร้างสดจาก seed ข้อเดิมจึงได้โจทย์เดิมเสมอทุกเครื่อง
ทุกข้อตรวจแล้วว่ามีคำตอบเดียว

**การปลดล็อก** ต้องผ่านข้อ n-1 ก่อนถึงเล่นข้อ n ได้ และต้องผ่าน 10 ข้อในระดับหนึ่ง
จึงจะเปิดระดับถัดไป

**ภารกิจและไอเทม** ทุกข้อมี 3 ภารกิจ (เวลา, จำนวนที่ลงผิด, ไม่ใช้ตัวช่วย) สำเร็จข้อละ +1 ตัวช่วย
โบนัส +2 ทุก 5 ข้อที่ผ่านในระดับนั้น ให้เฉพาะการผ่านครั้งแรก เพดาน 9 ชิ้น
ปุ่มใบ้ต้องมีตัวช่วยถึงกดได้ และเติมให้ถึง 2 ชิ้นทุกวันเพื่อกันตัน

**อื่นๆ** เล่นค้างไว้แล้วกลับมาต่อได้ · โจทย์ประจำวันหมุนระดับตามวันในสัปดาห์ ·
จับเวลาทุกข้อพร้อมเก็บสถิติ · จดเลขเองและเติมโน้ตอัตโนมัติ (เฉพาะระดับยากขึ้นไป) ·
ย้อนกลับและทำซ้ำ · โหมดกลางคืน · เสียง · โหมดเข้มงวด · หน้าสถิติพร้อมจำนวนวันเล่นติดกัน

## ค่าที่ปรับได้ง่าย

ทั้งหมดอยู่รวมกันด้านบนของสคริปต์ใน `index.html`

| ตัวแปร | ความหมาย |
|---|---|
| `PER_TIER` | จำนวนข้อต่อระดับ (200) |
| `PER_PAGE` | จำนวนข้อต่อหน้า (25) |
| `UNLOCK` | ผ่านกี่ข้อจึงเปิดระดับถัดไป (10) |
| `CHAL` | เป้าหมายเวลาและจำนวนที่ลงผิดของแต่ละระดับ |
| `MAX_ITEMS` | เพดานตัวช่วย (9) |
| `FILL_MIN_TIER` | ระดับต่ำสุดที่ใช้ปุ่มเติมจดได้ (3 = ยาก) |
| `TIERS` | ความยากของแต่ละระดับ (`maxTech` คือเพดานเทคนิค) |

## บันทึกการเปลี่ยนแปลง

### 1.1.0
- **ฟอนต์เก็บไว้ในเครื่อง** ไม่ต่อ Google Fonts อีกแล้ว ตรวจแล้วว่าเปิดแอปไม่มีคำขอออกอินเทอร์เน็ตแม้แต่รายการเดียว
  แบ่ง subset ตาม `unicode-range` เบราว์เซอร์โหลดเฉพาะชุดที่ใช้จริง (ไทย+ละติน รวม 118 KB)
- **แยกที่เก็บเกมที่เล่นค้าง** ออกจากก้อนข้อมูลหลัก เดิมเขียน 33 KB ทุกครั้งที่ลงเลข ตอนนี้เหลือ 308 bytes (ลดลง 99.1%)
- **เตือนก่อนทับเกมที่เล่นค้าง** เดิมเริ่มข้อใหม่แล้วของเดิมหายเงียบๆ
- **ปรับสีให้ผ่านเกณฑ์ WCAG AA** ตัวหนังสือรองจาก 3.58 เป็น 4.78 และตัวหนังสือบนปุ่มฟ้าจาก 4.24 เป็น 4.71
- **สำรองและกู้คืนข้อมูล** เป็นไฟล์ JSON ในหน้าตั้งค่า
- **ระบบเช็คอินรายวัน** ปฏิทินทั้งเดือน เช็คอินได้วันละครั้ง ย้อนหลังไม่ได้
  ได้ตัวช่วยสุ่ม 1-3 ชิ้น ครบ 7 วันติดกันได้โบนัสเพิ่ม 2 ชิ้น
  วันที่เช็คอินแล้วเป็นสีเขียว วันที่พลาดเป็นเส้นประสีแดง วันที่ยังไม่ถึงเป็นสีเทา
  (วันก่อนที่จะติดตั้งแอปไม่นับว่าพลาด)
- **สตรีคเปลี่ยนมานับจากการเช็คอิน** แทนการเล่นจบ พร้อมไอคอน 🔥 เมื่อยังต่อเนื่อง และ 🌱 เมื่อยังไม่เริ่ม
- **แสดงเลขเวอร์ชัน** ที่หน้าแรกและหน้าตั้งค่า
- **ตัดปุ่มล้างสถิติออก** ใช้การกู้คืนจากไฟล์สำรองแทน
